# Security

shamba runs locally and does not upload photos. If you find a security issue, please report it privately.

Email: biniyam.gashaw@hotmail.com

Please do not attach private photos to a public issue. A generated or public sample is enough.

## Scope

Examples of issues worth reporting:

- unsafe file handling in the web upload
- path traversal in model, report, or output paths
- a crash that exposes local file contents

Missed detections and wrong predictions are accuracy issues. Open a normal issue for those.
